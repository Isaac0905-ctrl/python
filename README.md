## 🚀 ¿Cómo funciona el flujo de trabajo?

Cada ejercicio sigue el mismo proceso usando las herramientas de [pypas.es](https://pypas.es):

**1. Moverse a la carpeta del ejercicio**
```bash
cd bucles/nombre_del_ejercicio
```

**2. Abrir el enunciado**
```bash
pypas doc
```
Esto abre el README del ejercicio con la descripción del problema y los requisitos.

**3. Plantear la solución**  
Se escribe el código en el archivo correspondiente aplicando los conceptos vistos hasta ese momento del curso.

**4. Lanzar los tests**
```bash
pypas test
```
Esto ejecuta la batería de tests del ejercicio. Si todos pasan ✅, la solución es correcta y el ejercicio está completado.

> Situarse dentro de la carpeta del ejercicio antes de lanzar los comandos es una buena práctica — así `pypas` sabe siempre sobre qué ejercicio está trabajando.
